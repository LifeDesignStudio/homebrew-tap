# Life Design Studio — Homebrew Tap

Homebrew tap for [Life Design Studio](https://github.com/LifeDesignStudio) macOS apps.

## Install

```sh
brew install --cask lifedesignstudio/tap/nanoswitch
```

(or `brew tap lifedesignstudio/tap` first, then `brew install --cask nanoswitch`)

## Casks

| Cask | Description |
|------|-------------|
| **nanoswitch** | A simpler, more beautiful Cmd+Tab that switches by window — [repo](https://github.com/LifeDesignStudio/NanoSwitch) |
